# SyncWrite — Client

This is the React frontend for the SyncWrite collaborative document editor.

Built with **React 19** and **Vite**.

## Setup

```bash
npm install
```

Create a `.env` file:

```env
VITE_GOOGLE_CLIENT_ID=your_google_oauth_client_id_here
```

## Run

```bash
npm run dev
```

Runs on **http://localhost:5173**
